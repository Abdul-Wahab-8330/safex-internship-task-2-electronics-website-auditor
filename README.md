# ⚡ AI-Assisted Website Quality Auditor (Electronics Focus)

A lightweight Streamlit web application that scrapes electronics product/store pages using BeautifulSoup and evaluates their quality, specifications, and trust signals using the Gemini API.

## Tech Stack
- Python & Streamlit (UI/Backend)
- Requests & BeautifulSoup4 (Web Scraping)
- Google GenAI REST API (Smart Analysis)
- Dotenv (Secure Configuration)
